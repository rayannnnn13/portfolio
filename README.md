# Portfolio de Rayan Ouakraf

CV numérique en HTML, CSS et TypeScript.

Site : https://rayannnnn13.github.io/portfolio/

## Développement

```sh
cd project
npm ci
npm run build
python3 -m http.server 8000
```

Les données du CV sont dans `project/data/cv.json`.

## Mettre à jour le site

Depuis `project`, lancer `npm run pages`, puis enregistrer et envoyer les changements vers GitHub. GitHub Pages publie le dossier `docs` de la branche `main`.
